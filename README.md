# iphone-photo-dl — 아이폰 사진을 Mac 으로 한꺼번에

아이폰의 사진·동영상을 USB 케이블로 Mac 에 한꺼번에 받는 프로그램입니다.

- **오래된 Mac 지원**: macOS 10.15(Catalina) 이상 — 2013년 맥북프로부터 최신 Apple Silicon Mac 까지 한 파일로 돕니다.
- **따로 설치할 것 없음**: macOS 에 들어 있는 사진 연결 기능(ImageCaptureCore — '이미지 캡처' 앱과 같은 통로)만 씁니다. Homebrew·Xcode 가 필요 없습니다.
- **이어 받기**: 이미 받은 파일은 건너뜁니다. 중간에 끊겨도 다시 실행하면 이어서 받고, 다음부터는 새 사진만 받습니다.
- **정리**: `2024/2024-05/IMG_1234.HEIC` 처럼 연/월 폴더로 나눠 저장하고, 파일 날짜를 찍은 날짜로 맞춥니다.
- **안전**: 아이폰의 사진을 지우지 않습니다.

## 설치 (Mac 마다 한 번)

1. Mac 에서 **터미널**을 엽니다 (응용 프로그램 > 유틸리티 > 터미널).
2. 아래 한 줄을 붙여 넣고 Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/sjidok750-creator/iphone-photo-dl/main/install.sh | bash
```

설치가 끝나면 바탕화면에 **`아이폰 사진 받기.command`** 가 생깁니다.

## 받기 전에 아이폰 설정 (속도에 가장 중요)

| 설정 위치 | 바꿀 값 | 이유 |
|---|---|---|
| 설정 > 사진 > **MAC 또는 PC로 전송** | **원본 유지** | '자동'이면 아이폰이 HEIC 를 JPG 로 바꾸면서 보내 느려집니다. 원본 유지가 가장 빠르고 화질 손실도 없습니다. |
| 설정 > 사진 > iCloud 사진 | **다운로드 및 원본 유지** (iCloud 사진을 쓸 때만) | 'iPhone 저장 공간 최적화'면 원본이 iCloud 에만 있는 사진은 케이블로 받을 수 없습니다. |
| 설정 > 디스플레이 및 밝기 > 자동 잠금 | **안 함** (받는 동안만) | 아이폰이 잠기면 전송이 멈춥니다. 잠금을 풀면 이어서 받습니다. |

## 사용법

1. 아이폰을 케이블로 Mac 에 연결하고 잠금을 풉니다. 처음이면 아이폰에 뜨는 **'이 컴퓨터를 신뢰하겠습니까?' → 신뢰**.
2. 바탕화면의 **`아이폰 사진 받기.command`** 를 더블클릭합니다.
3. 받을 폴더를 고릅니다 (기본: `사진(Pictures)/iPhone`, 외장 디스크도 됩니다).
4. 진행 표시가 나옵니다. 끝나면 Finder 가 저장 폴더를 엽니다.

```
연결됨: iPhone
사진 목록을 읽는 중… (사진이 많으면 몇 분 걸립니다)
목록 읽기 끝: 12,345개 (2분)

아이폰 전체: 12,345개 (사진 11,000 · 동영상 1,345), 85.2 GB
이미 받은 것: 10,000개 → 건너뜀
받을 것: 2,345개, 15.3 GB
저장 위치: /Users/나/Pictures/iPhone

받는 중 1,234/2,345 (52.6%) · 8.0 GB/15.3 GB · 28.1 MB/s · 남은 시간 5분
```

(위 숫자는 화면 모양을 보이려는 예시입니다.)

- Live Photo 는 사진(HEIC)과 동영상(MOV) 두 파일로 받습니다.
- 다시 실행하면 새로 찍은 것만 받습니다.
- 받지 못한 파일이 있으면 `저장폴더/.iphone-photo-dl/failed.txt` 에 적히고, 다시 실행하면 그것만 다시 받습니다.

### 터미널에서 쓰기

```bash
iphone-photo-dl                         # ~/Pictures/iPhone 에 받기
iphone-photo-dl /Volumes/외장디스크/iPhone  # 외장 디스크에 받기
iphone-photo-dl --list                  # 받지 않고 개수·용량만
iphone-photo-dl --dry-run               # 무엇을 어디에 받을지 목록만
iphone-photo-dl --since 2024-01-01      # 이 날짜 이후 찍은 것만
iphone-photo-dl --limit 20              # 앞의 20개만 (처음 시험용)
iphone-photo-dl --layout flat           # 연/월 폴더 없이 한 폴더에
iphone-photo-dl --layout folder         # 아이폰 폴더 그대로 (100APPLE …)
iphone-photo-dl --photos-only           # 사진만 / --videos-only 동영상만
iphone-photo-dl --help
```

`iphone-photo-dl` 명령이 없다고 나오면 `~/.iphone-photo-dl/bin/iphone-photo-dl` 로 실행하세요.

## 빠르게 받는 요령

1. **아이폰 '원본 유지'** (위 표) — 가장 효과가 큽니다.
2. **Mac 본체의 USB 포트에 바로** 꽂습니다 (허브·연장선 말고). 정품이나 인증 케이블을 씁니다.
3. **사진 앱·이미지 캡처 앱은 닫아 둡니다** — 같은 아이폰을 동시에 붙잡으면 느려지거나 연결이 안 될 수 있습니다.
4. 아이폰 13 Pro 의 라이트닝 단자는 **USB 2.0 속도**라, 이보다 빠르게 받을 수는 없습니다. 처음에는 오래 걸리고, 그다음부터는 새 사진만 받으니 금방 끝납니다.
5. 받는 동안 Mac 이 잠자기에 들지 않게 프로그램이 막아 둡니다 (노트북은 전원 연결 권장).

## 문제 해결

| 증상 | 할 일 |
|---|---|
| '아이폰을 찾지 못했습니다' | 잠금 해제·'신뢰' 확인 → 케이블을 다시 꽂기 → Mac 의 **이미지 캡처** 앱에서 아이폰이 보이는지 확인. 이미지 캡처에서도 안 보이면 macOS 쪽 연결 문제라 이 프로그램으로는 고칠 수 없습니다 (macOS 업데이트, 다른 케이블·포트 시도). |
| '목록을 읽는 중' 에서 멈춤 | 아이폰 잠금을 풀어 둡니다. 사진이 수만 장이면 몇 분 걸릴 수 있습니다. |
| '터미널이 … 폴더에 접근하려고 합니다' | **허용**을 누릅니다 (외장 디스크·바탕화면에 저장할 때 macOS 가 묻습니다). |
| 중간에 케이블이 빠짐 | 다시 꽂고 실행하면 받은 것은 건너뛰고 이어서 받습니다. |
| 파일 이름에 `(2)` 가 붙음 | 아이폰에 같은 이름(예: 다른 폴더의 IMG_0001)이 있어서 덮어쓰지 않으려고 붙인 것입니다. |

## 지우기

```bash
rm -rf ~/.iphone-photo-dl ~/Desktop/"아이폰 사진 받기.command"
rm -f /usr/local/bin/iphone-photo-dl
```

받은 사진과 저장 폴더 안의 `.iphone-photo-dl`(받은 목록)은 그대로 남습니다.

## 시험 상태

- 빌드 서버(GitHub Actions, macOS)에서 Intel·Apple Silicon 겸용으로 컴파일하고, 아이폰 없이 할 수 있는 자체 검사(이름·폴더 정리·이어 받기 판단·설치 스크립트)를 통과한 상태입니다.
- **실제 아이폰을 연결해 받는 시험은 아직입니다.** 처음에는 `--list` 와 `--limit 20` 으로 확인한 뒤 전체를 받으세요.

## 만든 방식 (개발자용)

- Swift 명령줄 도구, ImageCaptureCore 만 사용 (`Sources/`). 최소 macOS 10.15 (x86_64), 11 (arm64).
- `bash build.sh` — 이 Mac 용 빌드 (Xcode 명령줄 도구 필요), `bash build.sh universal` — 겸용.
- `iphone-photo-dl --self-test` — 기기 없이 로직 검사.
- 태그 `v*` 를 올리면 GitHub Actions 가 빌드·검사 후 릴리스에 `iphone-photo-dl-macos.tar.gz` 를 올리고, `install.sh` 는 최신 릴리스를 받습니다.
