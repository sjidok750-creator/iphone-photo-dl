# 아이폰 사진 받기 (iphone-photo-dl)

아이폰의 사진·동영상을 USB 케이블로 Mac 에 한꺼번에 받는 앱입니다.
**앱을 열고 아이폰을 꽂으면 저절로 받습니다.**

- 오래된 Mac 지원: macOS 10.15(Catalina) 이상 — 2013년 맥북프로부터 최신 Apple Silicon Mac 까지
- 따로 설치할 것 없음: macOS 에 들어 있는 사진 연결 기능('이미지 캡처' 앱과 같은 통로)만 씁니다
- 이어 받기: 받은 것은 건너뜁니다. 끊겨도 다시 꽂으면 이어서 받고, 다음부터는 새 사진만 받습니다
- 정리: `2024/2024-05/IMG_1234.HEIC` 처럼 연/월 폴더로 나눠 저장합니다
- 아이폰 공간 비우기(선택): 최근 사진부터 300장씩 받고, 맥에 저장된 것을 확인한 뒤 **물어보고** 아이폰에서 지웁니다

## 설치 (Mac 마다 한 번)

**터미널**(응용 프로그램 > 유틸리티 > 터미널)을 열고 아래 한 줄을 붙여 넣은 뒤 Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/sjidok750-creator/iphone-photo-dl/main/install.sh | bash
```

끝나면 앱이 저절로 열립니다. 다음부터는 **바탕화면** 또는 **응용 프로그램** 폴더의 **'아이폰 사진 받기'** 를 더블클릭하세요.
업데이트도 같은 한 줄로 합니다 (새 버전이 나오면 앱 화면에 '업데이트' 단추가 뜹니다).

## 다른 Mac 에서 (맥북 네오 등 최신 Mac 포함)

- 같은 한 줄로 설치합니다. 한 파일이 Intel 맥(2013년 맥북프로 등)과 Apple 실리콘 맥(M 칩·A 칩 — 맥북 네오 포함)에서 모두 돕니다.
- 맥북 네오처럼 USB-C 단자만 있는 Mac 은 **USB-C ↔ 라이트닝 케이블**로 아이폰 13 Pro 를 연결합니다. 아이폰 13 Pro 는 USB 2.0 속도라, 맥북 네오의 어느 USB-C 단자에 꽂아도 속도는 같습니다.
- Apple 실리콘 맥북은 처음 꽂는 USB 기기에 **USB 액세서리를 연결할지 묻는 창**을 띄울 수 있습니다 — **허용** 을 누르세요.
- 받은 목록은 저장 폴더마다 따로 관리됩니다. 지우기 시험(첫 묶음 20장)도 저장 폴더마다 한 번씩 합니다.

## 쓰는 법

1. '아이폰 사진 받기' 앱을 엽니다.
2. 아이폰을 케이블로 연결하고 잠금을 풉니다. 처음이면 아이폰에 뜨는 **'이 컴퓨터를 신뢰하겠습니까?' → 신뢰**.
3. 목록을 읽고 나면 **저절로 받기 시작**합니다. 끝나면 소리가 납니다.

저장 위치는 기본 `사진(Pictures)/iPhone` 이고, **바꾸기…** 로 외장 디스크 폴더도 고를 수 있습니다.

## 300장씩 받고 아이폰에서 지우기

창 아래 **'최근 사진부터 300장씩 받고, 맥에 저장된 것을 확인한 뒤 아이폰에서 지울지 묻기'** 가 켜져 있으면 (처음에는 켜져 있음):

1. 가장 최근 사진 300장을 받습니다 (이미 받은 것은 다시 받지 않습니다).
2. 300장 모두 맥에 파일이 있고 크기가 맞는지 하나하나 확인합니다.
3. **'아이폰에서 300장 지우기'** 와 **'지우지 않고 다음 묶음'** 중 고르라고 묻습니다. 그 사이 **폴더 열기** 로 받은 사진을 먼저 볼 수 있습니다.
4. 고르면 다음 300장으로 넘어가고, 끝까지 되풀이합니다.

안전장치:
- 맥에 **원본 그대로**(파일 형식과 바이트 수가 아이폰과 같음) 저장된 사진만 지웁니다. 받지 못했거나, 아이폰이 변환해서 보낸 사본(HEIC → JPG)만 있는 사진은 지우지 않습니다 — 그래서 지우기 전에 아이폰을 **'원본 유지'** 로 두세요.
- 이 저장 폴더에서 처음 지울 때는 **첫 묶음을 20장만** 합니다. 지운 뒤 아이폰과 맥을 확인하고 계속하세요.
- Live Photo(사진+동영상)와 편집본은 원본과 한 장으로 묶어, 모두 받은 뒤에만 함께 지웁니다.
- Enter 키는 '지우지 않고 다음' 입니다. 질문이 뜬 직후 1.5초 동안은 지우기 단추가 눌리지 않습니다.
- 지운 파일 목록은 저장 폴더 안 `.iphone-photo-dl/deleted.tsv` 에 남습니다.

주의:
- **iCloud 사진이 켜져 있으면** 아이폰에서 지울 때 iCloud 와 다른 기기에서도 지워질 수 있습니다 ([Apple 안내](https://support.apple.com/en-ae/104967)). 이 경우 앱 화면에 주의 문구가 나옵니다. iCloud 사진을 쓰면 케이블로는 지우기가 막힐 수도 있습니다.
- 케이블로 지운 사진이 아이폰 '최근 삭제된 항목' 에 30일 동안 남는지는 아직 확인하지 못했습니다. 처음 한 묶음을 지운 뒤 아이폰 사진 앱에서 확인해 보세요.
- 지우기를 원하지 않으면 체크를 끄면 됩니다 (그러면 예전처럼 오래된 것부터 모두 받기만 합니다).

## 받기 전에 아이폰 설정 (잘 되고 빨라지는 데 가장 중요)

| 설정 위치 | 바꿀 값 | 이유 |
|---|---|---|
| 설정 > 사진 > **MAC 또는 PC로 전송** | **원본 유지** | '자동'이면 아이폰이 사진·동영상을 바꿔 가며 보내 느리고, 멈추거나 실패하기 쉽습니다. |
| 설정 > 디스플레이 및 밝기 > **자동 잠금** | **안 함** (받는 동안만) | 아이폰이 잠기면 전송이 멈춥니다. 잠금을 풀면 앱이 저절로 이어서 받습니다. |
| 설정 > 사진 > iCloud 사진 | **다운로드 및 원본 유지** (iCloud 사진을 쓸 때만) | 'iPhone 저장 공간 최적화'면 원본이 iCloud 에만 있는 사진은 케이블로 받을 수 없습니다. |

## 잘 안 될 때

| 화면 | 할 일 |
|---|---|
| '아이폰을 USB 케이블로 연결하세요' 에서 그대로 | 잠금 해제·'신뢰' 확인 → 케이블을 Mac 본체에 바로(허브 말고) 다시 꽂기 → Mac 의 **이미지 캡처** 앱에서 아이폰이 보이는지 확인. 이미지 캡처에서도 안 보이면 macOS 쪽 문제라 이 앱으로는 고칠 수 없습니다. |
| '아이폰 잠금을 풀어 주세요' | 아이폰 잠금을 풀면 저절로 이어집니다. |
| (Apple 실리콘 맥북) 꽂아도 아무 반응 없음 | USB 액세서리 연결 창에서 '허용 안 함'을 눌렀을 수 있습니다. 시스템 설정 > 개인정보 보호 및 보안 > 액세서리 에서 허용으로 바꾸고 다시 꽂으세요. |
| '사진 목록을 읽는 중' 이 오래 감 | 사진이 수만 장이면 몇 분 걸립니다. 5분 넘게 그대로면 케이블을 뺐다 다시 꽂으세요. |
| '잠깐 멈췄습니다' | 케이블을 뺐다 다시 꽂으면 받은 것은 건너뛰고 이어서 받습니다. |
| 'N개는 받지 못했습니다' | **다시 받기** 를 누르세요. 계속 안 되면 위 표의 '원본 유지' 를 확인하세요. |

**기록 보기** 단추를 누르면 무엇이 잘못됐는지 적힌 기록(`~/Library/Logs/iphone-photo-dl.log`)이 열립니다. 문제가 계속되면 이 기록을 보내 주세요.

앱이 하는 일 (잘 되게 하려고 넣은 것):
- 전송이 멈추면 그 파일을 저절로 다시 시도하고, 계속 멈추는 파일은 건너뛰고 나머지를 받습니다.
- 사진 앱·이미지 캡처 앱이 아이폰을 함께 붙잡고 있으면 닫고 화면에 알려 줍니다.
- 아이폰이 사진을 변환해서 보내는 것이 보이면 '원본 유지' 로 바꾸라고 바로 알려 줍니다.
- 받는 동안 Mac 이 잠자기에 들지 않게 합니다 (노트북은 전원 연결 권장).

## 터미널에서 쓰기 (선택)

```bash
iphone-photo-dl --cli                   # ~/Pictures/iPhone 에 받기
iphone-photo-dl /Volumes/외장디스크/iPhone  # 다른 폴더에 받기
iphone-photo-dl --list                  # 받지 않고 개수·용량만
iphone-photo-dl --limit 20              # 앞의 20개만 (시험용)
iphone-photo-dl --since 2024-01-01      # 이 날짜 이후 찍은 것만
iphone-photo-dl --batch 300             # 최근 것부터 300장씩 받고, 묶음마다 지울지 묻기 (y 입력 때만 지움)
iphone-photo-dl --help                  # 그 밖의 옵션
```

`iphone-photo-dl` 명령이 없다고 나오면 `~/.iphone-photo-dl/bin/iphone-photo-dl` 로 실행하세요.

## 지우기

```bash
rm -rf "/Applications/아이폰 사진 받기.app" ~/Desktop/"아이폰 사진 받기" ~/.iphone-photo-dl
```

받은 사진과 저장 폴더 안의 `.iphone-photo-dl`(받은 목록)은 그대로 남습니다.

## 시험 상태

- 빌드 서버(GitHub Actions)에서 Intel·Apple Silicon 겸용으로 만들고, 아이폰 없이 할 수 있는 자체 검사·앱 화면·설치 시험을 통과했습니다 (실행해 본 macOS 는 15.x·26 Tahoe, Intel·Apple 실리콘).
- **macOS 10.15·11 과 실제 아이폰으로는 아직 시험하지 못했습니다.** 문제가 생기면 '기록 보기' 의 기록을 보내 주세요.

## 만든 방식 (개발자용)

- Swift + AppKit + ImageCaptureCore (`Sources/`): `Engine.swift`(연결·받기·감시), `AppUI.swift`(창), `CLI.swift`(터미널), `Core.swift`(계획·받은 목록).
- 최소 macOS 10.15 (x86_64), 11 (arm64). 릴리스 빌드는 Xcode 16 — macOS 10.15 를 공식 지원하는 마지막 Xcode (Xcode 26 은 11 이상, 27 은 12 이상).
- `bash build.sh` → `build/아이폰 사진 받기.app`. `iphone-photo-dl --self-test` 로 기기 없이 로직 검사.
- 태그 `v*` 를 올리면 GitHub Actions 가 빌드·검사 후 릴리스에 `iPhonePhotoDL-app.zip` 을 올립니다.
